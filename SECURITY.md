# Security policy

This library runs inside NUI pages and only reads the game frame on the client. It never sends
pixels anywhere.

If you find a security problem, report it privately through
[GitHub security advisories](https://github.com/mur4i/mri-fivem-liquid-glass/security/advisories/new)
instead of a public issue. You will get an answer within a few days.

Only the latest release receives fixes.
