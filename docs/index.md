features:
  - title: Frosted glass
    details: The game blurred behind any element, following its border-radius, the opacity of its parents and overflow clipping.
  - title: Liquid glass
    details: A bevelled rim that bends the sharp game image, with color split and a specular highlight. Tunable per element.
  - title: Diamond, gem and kaleidoscope
    details: A diamond outline, a faceted cut gem that splits the scene into prisms, and a kaleidoscope that mirrors what is behind it.
  - title: Built for the game
    details: Survives loading screens, black frames and lost hooks, and never stalls the GPU to read pixels. resmon 0.00 ms.
  - title: Readable text
    details: Every element gets data-glass-backdrop="bright|dark" so your text can flip color over bright scenes.
  - title: Tiny and framework free
    details: One module with zero dependencies, about 18 KB minified. React, Vue, Svelte or plain HTML.
